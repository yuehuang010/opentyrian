# HD remaster plan

The user is pursuing a **full HD remaster** of OpenTyrian. The phased plan lives in `plan/REMASTER_PLAN.md` (in-repo, version-controlled).

Chosen approach (decided 2026-07-05): **"HD skin, plays identical"** — keep gameplay in the original 320×200 logical coordinate space (so all hardcoded gameplay/layout math stays valid), render upscaled HD visuals on top. NOT widescreen (that's out of scope — it would touch gameplay bounds).

Key architectural fact: the engine is **8-bit indexed-color**; fades, ship/enemy recoloring, and palette cycling are all palette manipulation. HD (truecolor RGBA) art requires moving to a **truecolor GPU compositor** and reimplementing those palette effects as tint/alpha/shader ops. That engine change (Phase 1) is the crux, not resolution.

**Phases 0, 1, 2 (backdrops), 4 (CRT), 5, and 6 (render interpolation) are landed** on branch `hd-remaster`. Phase 5 (free scaling/fullscreen + persisted window size) done. **Phase 6** = fixed-timestep sim + render interpolation via a **display-list capture/replay** (`src/interp.c`), gated by `[video] highfps` (default off): sim runs once per tick (byte-identical), draws are recorded at the blit choke points tagged by entity, and `flight_present()` replays them interpolated between ticks. Sim rate stays ~35Hz (raising it = separate balance-changing follow-on). Known: superpixels + smoothie/lava/water filters degrade to tick-rate on interp frames. Compiles clean + headless demo runs the path crash-free; **on-device visual A/B still pending** (no display in build env). Details below are the earlier Phase 0/1 record.

**Phase 0 + Phase 1 were DONE and verified** (as of 2026-07-05). The title-screen vertical slice works: `scale_and_flip` (video.c) has an HD branch that draws a 4×-upscaled backdrop behind the color-keyed indexed logo/version/menu, with a fade via texture color-mod; Phase 0 added `SDL_WINDOW_ALLOW_HIGHDPI` + renderer-output-size layout + mouse point/pixel reconciliation. New symbols: `hd_mode`/`hd_title_active`/`hd_title_fade` (video.h), `get_live_palette()` (palette.h). Config toggle `[video] hd` (default on). HD asset `hdtitle.dat` (format `HDPX`+w+h+RGBA) generated by `tools/hd_extract.py` (pure stdlib, Lanczos — a PLACEHOLDER for a real AI upscaler in Phase 2), written into the data dir (gitignored). Verified by `SDL_RenderReadPixels` framebuffer readback (macOS `screencapture` is blocked — no Screen Recording permission for the terminal).

Next: Phase 2 (asset pipeline: real AI upscaler + more assets/sprites). Slice anchors: `titleScreen()` at `tyrian2.c:3235`; backdrop = `tyrian.pic` image #4, palette 8.

Implementation to be delegated to Sonnet agents — see [use-sonnet-agents-for-implementation.md](use-sonnet-agents-for-implementation.md). Runtime flag gotcha: [data-dir-flag-is-t-not-d.md](data-dir-flag-is-t-not-d.md).
