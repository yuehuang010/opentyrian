# lds_gm_map.txt - OPL2 voice fingerprint -> General MIDI program map
#
# Used by tools/lds_to_midi.c to decide what GM instrument (0-127) a decoded
# OPL2 voice should sound like when the MIDI is rendered through a
# soundfont/synth (e.g. fluidsynth), and optionally to transpose it.
#
# Each fingerprint is an 8-hex-digit FNV-1a hash over an OPL channel's
# timbre-defining registers (modulator + carrier {0x20,0x40,0x60,0x80,0xE0}
# offsets, plus the 0xC0+ch feedback/connection register) at the moment a
# note-on happens. Different instruments in the same track produce different
# fingerprints; the same instrument reused later reproduces the same one.
#
# Run `tools/lds_to_midi <data_dir> <out_dir> <song>` and read the resulting
# hdmusic_NN.patches report to see which fingerprints appear, on which OPL
# channels, how often, and whether they're currently mapped. Copy the
# fingerprints you care about into this file with your chosen GM program.
#
# Format (whitespace separated, '#' comments allowed):
#   <8-hex-fingerprint>  <gm_program 0-127>  [semitone_transpose]  [volume 0-127]  [cents -99..99]
#
# LDS_MIN_GATE_MS (env, float ms, default 0/off): stretches emitted MIDI note
# gates shorter than this floor (e.g. fast chord-stab voices) so sampled GM
# instruments have time to speak instead of rendering as pitchless blips.
# Only affects the emitted .mid; the .notes dump still reports true gates.
#
# volume is a per-instrument mix level (MIDI CC7, default 100) emitted when
# the fingerprint takes over a channel; use it to push leads forward and
# tuck accompaniment back without touching the decoded dynamics.
#
# gm_program follows the General MIDI Level 1 program list (0 = Acoustic
# Grand Piano, 24 = Nylon Guitar, 33 = Electric Bass (finger), 56 = Trumpet,
# 61 = Brass Section, 80 = Lead 1 (square), 81 = Lead 2 (sawtooth), etc.)
#
# semitone_transpose is optional and defaults to 0; it's applied to every
# note emitted on a channel while that fingerprint is active (useful if an
# OPL voice's synthesized octave doesn't match its GM counterpart's natural
# register).
#
# cents is optional and defaults to 0; it's a per-instrument fine-tuning
# offset (MIDI RPN 1, channel fine tuning, +-100 cent range) emitted when
# the fingerprint takes over a channel, on top of the semitone transpose.
# Use it to correct a soundfont preset's own tuning error against the OPL
# original's actual chip frequency (see tools/validate_pitch.py TEST B,
# and internal/hd-music-pitch-report.md), not to change which note plays.
#
# Example (not applied until you uncomment/edit with real fingerprints from
# a .patches report):
# 1a2b3c4d  81  0  100  0
